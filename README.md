# Code VIA Technologies root Pages host

Publishes the hostname-root `app-ads.txt` used by the developer website for Gilded Pyramid Solitaire and Gilded Peaks Solitaire. The main app portfolio remains in the existing `code-via-technologies-protfolio` repository and its project Pages path.

The seller entry is the shared Google AdMob publisher, not an app or ad-unit ID. Keep the root plain-text file available over HTTPS. The index redirects visitors to the existing portfolio without moving or replacing any app pages.

Publishing source: main branch, repository root. `.nojekyll` keeps these files static.
